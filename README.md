# Naveen Mobile Shop

Website for Naveen Mobile Shop, near I ❤ Chaukhutiya, Chaukhutiya, Uttarakhand.
The shop sells mobiles and accessories and repairs phones.

## Features

- Home, Our shop (photo gallery) and Find us (map and directions) pages
- "Take me to shop" button that opens Google Maps directions
- Dark and light mode, with dark as the default
- Mobile-first design with a sticky Call and Directions bar
- Local SEO: page titles, descriptions, structured data, sitemap and robots file

## Built with

Next.js, React and Tailwind CSS

## Run it locally

    npm install
    npm run dev

Then open http://localhost:3000.

## Edit shop details

Phone number, address, opening hours, Instagram link, services and map location
are all in `lib/site.js`.
